Placeholder page. Steps for a demo session:

  1. Upload a contract PDF (POST /api/contract) or load the demo contract (POST /api/contract/demo)
  2. Give consent (POST /api/consent)
  3. Start a session (POST /api/session/start)
  4. Connect to /ws/session/{session_id} for live transcript + alerts
  5. End the session and view the report (POST /api/session/{id}/end, GET /api/session/{id}/report)
